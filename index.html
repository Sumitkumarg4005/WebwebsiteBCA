Programming Languages

Find out what each language is good at, then open its code to see how “Hello World” looks.

C

C is a general-purpose, procedural programming language developed by Dennis Ritchie in 1972 at Bell Laboratories. It is a powerful and structured programming language. C is known as a middle-level language because it supports both high-level and low-level features. It is simple, fast, efficient and portable. C is widely used to develop operating systems, software and applications.

C example

#include <stdio.h>

int main() {
  printf("Hello World");
  return 0;
}

C++

C++ is a general-purpose programming language developed by Bjarne Stroustrup in 1985. It is an extension of the C language. It supports both procedural and object-oriented programming. C++ is known for its speed and efficiency. It is widely used in game development, software development and system programming.

C++ example

#include <iostream>

int main() {
  std::cout << "Hello World";
  return 0;
}

Python

Python is a high-level, general-purpose programming language created by Guido van Rossum in 1991. It is known for its simple and easy-to-understand syntax. Python is easy to learn and use. It supports different programming styles. It is widely used in web development, artificial intelligence, data science and automation.

Python example

print("Hello World")

Java

Java is a high-level, object-oriented programming language developed by James Gosling at Sun Microsystems in 1995. It is known for its platform independence, which means Java programs can run on different operating systems. It is secure, reliable and easy to use. Java is commonly used for developing web, mobile and desktop applications.

Java example

class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

JavaScript

JavaScript is a high-level programming language mainly used to make websites interactive and dynamic. It was created by Brendan Eich in 1995. It works along with HTML and CSS to improve the functionality of websites. JavaScript is also used for server-side development and web applications.

JavaScript example

console.log("Hello World");

C#

C# (C-Sharp) is a modern, object-oriented programming language developed by Microsoft in 2000. It is designed to make software development easier and more efficient.C# is used to develop desktop applications, web applications, games and mobile applications. It runs mainly on the .NET platform.

C# example

using System;

class Program {
  static void Main() {
    Console.WriteLine("Hello World");
  }
}

PHP

PHP stands for Hypertext Preprocessor. It is a server-side scripting language created by Rasmus Lerdorf in 1994. It is mainly used for developing dynamic websites and web applications. PHP can easily work with databases such as MySQL. It is widely used in web development.

PHP example

<?php
echo "Hello World";
?>

Go

Go is a general-purpose programming language developed by Google in 2009. It was designed to make programming simple, fast and efficient. Go has a simple syntax and supports concurrent programming. It is mainly used for cloud computing, networking, backend development and large-scale applications.

Go example

package main

import "fmt"

func main() {
  fmt.Println("Hello World")
}

History of Programming Languages

A short journey through the development of important programming languages.

1957

FORTRAN

FORTRAN was developed by IBM. It was mainly used for scientific calculations, engineering and mathematical computing.

1958

LISP

LISP was developed by John McCarthy. It became an important language for artificial intelligence research and symbolic processing.

1959

COBOL

COBOL was designed mainly for business applications, banking systems and large-scale data processing.

1964

BASIC

BASIC was created to make programming easier for beginners. It became popular in schools and personal computers.

1970

Pascal

Pascal was developed by Niklaus Wirth. It was designed to teach programming concepts and structured programming.

1972

C

C was developed by Dennis Ritchie at Bell Labs. It became widely used for system programming and operating systems.

1983

C++

C++ was developed by Bjarne Stroustrup as an extension of C. It introduced object-oriented programming features.

1991

Python

Python was created by Guido van Rossum. It became popular because of its simple syntax and easy readability.

1995

Java, JavaScript and PHP

Java, JavaScript and PHP appeared in 1995. They became important in software development and web development.

2000

C#

C# was developed by Microsoft. It became an important language for building desktop, web and other applications.

2009

Go (Golang)

Go was developed at Google. It was designed to make programming simple, fast and efficient.

2014

Swift

Swift was introduced by Apple. It is mainly used to develop applications for iPhone, iPad and other Apple devices.
